# STICKS & BONES campaign artwork

Owner-approved artwork created with OpenAI image generation from the project's character sheets,
Puerto Rico environment art and wordmark on 2026-11-18. Source PNGs are preserved here without edits.

| Source | Intended use |
| --- | --- |
| `source/sticks-and-bones-banner.png` | Wide game-title banner and social sharing master |
| `source/sticks-and-bones-instagram-square.png` | Square Instagram feed post |
| `source/sticks-and-bones-instagram-story.png` | Portrait Instagram Story |

The public share image is `public/social/sticks-and-bones-og-v1.jpg` (1200 × 630 JPEG).
It is resized from the wide master, encoded at quality 82 with mozjpeg, with metadata removed.
These promotional sources are not game-runtime assets and are not loaded or cached by the game.

`index.html` contains static Open Graph and Twitter large-image metadata, with absolute HTTPS URLs
for the canonical GitHub Pages page and its image. No JavaScript execution is needed by crawlers.
The square and Story source files remain in the repository for posting; link previews use the wide JPEG.

Share the Pages URL, not the github.com repository URL. Social platforms may retain an old preview;
request a re-scrape in the platform's sharing debugger after publishing. Use a new image filename when
replacing the banner so already cached image bytes are not mistaken for the new artwork.
