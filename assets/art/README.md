# Art assets

These are the owner's source art files, kept exactly as supplied, with original
filenames and byte-identical content. **Don't edit, re-encode or overwrite them.**
Derivatives go in new files with their own manifest entries.

| Folder | Contents |
| --- | --- |
| `characters/` | Roberto “Cousin”: expression atlases (one byte-identical duplicate), two 6-frame gesture strips, two opaque turnaround reference sheets; Story cast atlases; two single supporting portraits (worker, representative) |
| `tiles/` | Four domino material sprites (two faces without pips, two backs) |
| `effects/` | Eight independent effect sprites |
| `tables/` | Two tabletop surfaces |
| `environments/` | Eight Puerto Rico settings (1672×941), including the cave-entrance rest area |
| `props/` | Blank evidence card on warm wood (1086×1448) |

The full measured inventory, frame rectangles and runtime plan are in
[`docs/ASSETS.md`](../../docs/ASSETS.md). `npm run assets:verify` checks these files.
